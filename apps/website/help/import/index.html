Import from Pulley, Carta or Cake

Bring your cap table over from your old tool in about two minutes, and check every total against it before anything is saved. Pulley closes on December 8, 2026, so do this first.

Orange boxes mark what to look at or click. Click a screenshot to enlarge it.

Before you start

Download these from your old tool. Capfolder's Import screen shows the same steps for the tool you pick.

  • Pulley: Dashboard → Download Cap Table (keep All time ticked), or Company → Reports → Detailed Cap Table → Generate.
  • Carta: Cap Table → Run reports → the Cap table report (Detailed).
  • Cake Equity: Compliance → Reporting → Exports → Cap table (XLSX). SAFEs are in Noteholders (CSV).
  • Keep the old tool open in another window: you'll copy a few totals from its summary in step 4.

Also download every signed document (Pulley: Company → Data Room → Download All). The export holds the numbers, not the paperwork.

1. Open Import

In a new company folder, click Import a cap table under the empty cap table, or any Import button in the Get started list. When you create a company, the start screen also offers Import from Pulley or Carta.

2. Pick your old tool and choose the file

Under Where is your cap table now?, pick Pulley, Carta, Cake Equity, An OCF export (.zip) or Any spreadsheet. Then click Choose file… and pick the .xlsx or .csv you downloaded.

An OCF export (.zip) brings its full history and goes straight to Check and save: there are no columns to match.

3. Match the columns

Capfolder finds the row with the column names and guesses what each column holds. Check the guesses against the first values on the right, fix any that are wrong, and click Continue.

4. Compare with your old tool

On Check and save, fill in Compare with Pulley (or Carta, or Cake) with the totals your old tool shows on its summary. Only Fully diluted is required. Each number you type gets ✓ Match, or a line that says how far off it is.

  1. If every number matches, click Save to the cap table.
  2. If one doesn't, look for the reason first: a missing row, a column matched to the wrong field. If you know why it differs, tick Accept with a note (it's saved in the record) and write why.
  3. Rows with a problem (a date it can't read, more vested than granted) must be fixed in the file or the column matching before you can save.
If the file has a "vested so far" column, Capfolder works out each grant's vesting itself. When the two differ by more than one share, a folded note lists the grants to check (usually the vesting start or the cliff).

5. Add your documents, then finish the move

After saving, Documents opens: the export didn't include your signed documents, so drop them in there. Back on the cap table, the Before you cancel Pulley card lists what's left to do. Tick each step as you go.

Words used here

Fully diluted
Every share that exists or could exist: issued shares, options and the whole option pool. Fully diluted shares, explained.
Pool available
Shares in the option pool that haven't been granted yet. Option pools, explained.
Cap table
The list of who owns what in your company. What is a cap table?
OCF
The Open Cap Format: an open file format for cap tables. Capfolder stores and exports it.
