Install a local AI

A local AI is a free app that runs an AI model on your own computer. Capfolder can use it with no account, no bill, and nothing leaving your laptop. Pick one of the two below. Both are free.

Already have Ollama or LM Studio? Skip to Connect Ollama or LM Studio.

Which one?

LM Studio
A normal app with buttons. Best if you've never used a terminal.
Ollama
Small, runs in the background, and you download models with one command. Best if you're happy in a terminal.

Any recent laptop works. 16 GB of memory is comfortable; 8 GB works with a small model.

Option A: LM Studio

  1. Download LM Studio from lmstudio.ai and install it.
  2. Open it, go to Discover, and download a small model (3–8B). LM Studio marks the ones that fit your computer.
  3. Go to the Developer tab and switch the server on, so it says Running.

Option B: Ollama

  1. Download Ollama from ollama.com and install it. Open it once and it keeps running in the background.
  2. Open a terminal (Mac: Terminal, Windows: PowerShell) and download a model. It's a few GB, once: 
    ollama pull llama3.1

Then connect it to Capfolder

Follow Connect Ollama or LM Studio. In short: open Settings → AI, click Look again, and pick your model in AI in use.
