Install a local AI

A local AI is a free app that runs an AI on your own computer. Capfolder can use it to answer questions about your cap table, with no account, no bill and nothing leaving your laptop. Never done this before? That's fine: this guide assumes nothing.

Already have Ollama or LM Studio? Skip to Connect Ollama or LM Studio.

What you need

  • A Mac or Windows computer from the last few years, with 8 GB of memory or more (16 GB is comfortable).
  • About 10 GB free disk space for the app and one model.
  • 15 minutes and an internet connection for the download. After that it works offline.

Pick one

LM Studio: easiest if you've never used a terminal
A normal app with buttons. You search for a model and click download.
Ollama: smallest, if you're happy typing one command
Runs in the background. You download a model with one line.

Both are free. You only need one.

Option A: LM Studio

  1. Go to lmstudio.ai and click the download button for your computer.
  2. Install it. Mac: open the downloaded file and drag LM Studio into Applications. Windows: open the downloaded setup file and click through it.
  3. Open LM Studio and go to the Discover tab (the magnifying glass, or ⌘2 on a Mac, Ctrl+2 on Windows).
  4. Search for gemma and download a small version. LM Studio shows which ones fit your computer. (LM Studio's guide to downloading a model)
  5. When it's done, go to the Developer tab and switch the server on, so it says Running. (LM Studio's server guide)

Option B: Ollama

  1. Go to ollama.com/download and download it for your computer.
  2. Install it. Mac: open the downloaded file, drag Ollama into Applications and open it. Windows: open the setup file and click through it. Ollama then runs in the background.
  3. Open a terminal. Mac: press ⌘ Space, type Terminal and press Enter. Windows: open the Start menu, type PowerShell and press Enter.
  4. Copy this line, paste it into the terminal and press Enter: 
    ollama pull gemma4:e2b
    It downloads the model once (about 7 GB). When it says success, you're done. (Ollama's quickstart)

Then connect it to Capfolder

Follow Connect Ollama or LM Studio. In short: open Settings, find the AI box, click Look again, and pick your model in AI in use.
