Install the Capfolder beta

Capfolder is in beta. We don't have Apple or Microsoft certificates yet, so your computer warns you the first time you open it. That warning is expected, and it takes about a minute to get past.

Haven't downloaded it yet? Get Capfolder here.

macOS

  1. Open the downloaded .dmg file and drag Capfolder into Applications.
  2. Open Capfolder from Applications. macOS warns you and doesn't open it yet. Close the warning.
  3. Open System Settings and go to Privacy & Security.
  4. Scroll down to Security and click Open Anyway next to the message about Capfolder.
  5. Confirm with your password or Touch ID. From now on it opens normally.

If macOS says Capfolder "is damaged": open Terminal, paste this line and press Enter, then open Capfolder again.

xattr -cr /Applications/Capfolder.app

Windows

  1. Open the downloaded setup file.
  2. If a blue window says Windows protected your PC, click More info.
  3. Click Run anyway, then click through the installer.

Linux

  1. Download the AppImage.
  2. Right-click it, open Properties and allow it to run as a program.
  3. Open it.

Why does this happen?

Apple and Microsoft warn about any app that isn't signed with one of their paid certificates. The warning means the app is unsigned, not that it has been found to be harmful. Capfolder's code is public on GitHub, and each release lists its files and checksums.
