Capfolder · Features · Import

Move your cap table from Pulley or Carta before Dec 8

Free · open source · macOS, Windows and Linux

In short: Capfolder imports a Pulley, Carta or Cake Equity export, an OCF file or any spreadsheet, and won't save it until its totals match your old tool to the share. Then a checklist walks you through everything to keep before you cancel.

The problem

Pulley closes on December 8, 2026, and the only move it offers is to Carta. Leaving any cap table tool means trusting a spreadsheet export: if a row is missing or a column is read wrong, you find out in your next due diligence, not today. And the export holds only numbers. The signed documents that prove each line live somewhere else.

How it works

  1. Export the detailed cap table from Pulley, Carta or Cake (Capfolder shows the exact menu path for each).
  2. Choose the file in Capfolder's Import screen. An OCF export goes straight to the check.
  3. Match the columns. Capfolder guesses which column is the name, shares, strike, vesting start and so on; you fix any wrong guess.
  4. Compare with your old tool. Type in the totals it shows. Only fully diluted is required.
  5. Save, then drop in your signed documents and tick off Before you cancel.

What Capfolder checks for you

  • Totals, to the share. Fully diluted must match the number you type from your old tool. Each share class, options outstanding, pool available, the SAFE total and the number of stakeholders are checked too when you fill them in. A mismatch blocks saving unless you accept it with a note, which is kept in the record.
  • Every row. A date it can't read, a share count that isn't a whole number, a SAFE without an amount, or more shares vested than granted stops the import, with the row number.
  • Vesting so far. When the file has a "vested" column, Capfolder works out each grant's vesting from its start, length and cliff, and lists any grant where the two differ by more than one share.
  • The same person twice. People are matched by email, then by name, so one investor doesn't become two.
  • Proof of where it came from. Every imported record is marked with the file it came from, and a copy of the file is kept in your folder's docs/_imports/.

Where your data goes

Nowhere. The file is read on your computer and the cap table is written as plain files in your company folder. The import never touches the internet. Only documents you later send for signature pass through the signing relay, and only until they're signed.

What it doesn't do yet

  • It can't log in to Pulley or Carta for you: you download the export and the documents yourself.
  • Spreadsheets need one holding per row. An OCF file with records Capfolder can't apply yet (conversions, stock splits) is refused with a list instead of half-imported.
  • Round modelling, 409A valuations and employee logins aren't built. See the roadmap.

Questions people ask

Which tools can I import from?

Pulley, Carta and Cake Equity exports (.xlsx or .csv), an Open Cap Format (OCF) export (.zip), or any spreadsheet with one holding per row.

Does the import bring my signed documents?

No. Cap table exports hold the numbers only. Download your signed documents separately (in Pulley: Company → Data Room → Download All) and drop them into Capfolder's Documents, which files each one against the cap table.

What if a total doesn't match?

Capfolder shows how far off it is and doesn't save until you either fix the file or column matching, or accept the difference with a note. The note is saved in the record.

Is my cap table uploaded anywhere?

No. The import runs on your computer, and the result is plain files in your company folder. Only documents you send for signature ever reach a server.

Do I need a Pulley or Carta account afterwards?

No. Once everything is imported and your documents are saved, you can cancel. Capfolder's Before you cancel card lists what to check first.
